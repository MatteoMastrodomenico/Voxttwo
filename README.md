# Voxttwo

**Record. Transcribe. Organize. Translate.**

Voxttwo is a modern Android application designed to transform spoken content into organized and accessible text.

It combines audio recording, speech-to-text transcription, file organization and translation in a single multilingual interface designed for everyday use, study and personal productivity.

## ✨ Features

- 🎙️ Record audio directly from your Android device
- 📝 Convert speech into text
- 📂 Organize recordings using folders and subfolders
- 🔄 Move recordings between folders
- 🎵 Import audio files
- 🎬 Import video files for audio processing and transcription
- 📤 Share generated transcripts
- 🌍 Translate transcribed content
- 🌙 Modern Android interface with dark mode
- 🔎 Manage and access previous recordings from the Library
- 📱 Native Android application

## 🌍 Languages

Voxttwo provides multilingual support for six languages:

🇬🇧 English  
🇮🇹 Italian  
🇪🇸 Spanish  
🇫🇷 French  
🇩🇪 German  
🇹🇷 Turkish

The application interface and its language-processing features are designed around these languages.

## 🔐 Privacy

Voxttwo follows an offline-first design philosophy.

Recordings and transcripts are managed on the user's device.

Speech-recognition availability and offline processing may depend on the speech services and language packs installed on the Android device.

## ⚙️ Requirements

- Android device
- Microphone access for audio recording
- Storage space for recordings and imported media
- Compatible Android speech-recognition services
